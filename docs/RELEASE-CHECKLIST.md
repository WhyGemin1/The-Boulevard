# Release readiness checklist

This public-safe checklist contains no merchant-specific data. Keep evidence and financial records in private systems.

| Gate | Required evidence |
| --- | --- |
| Catalog | Explicit approved assortment; imports reviewed; no unintended exposure through search, menus or direct links |
| Supplier | Current authorization, fulfillment, returns and damage procedures |
| Product | Correct variants, unique identifiers or documented exceptions, stock and media permissions |
| Economics | Known costs and fees, positive contribution at the approved target |
| Storefront | Desktop/mobile navigation, keyboard and reduced-motion checks |
| Source | Reviewed pull request, tests, private configuration, rollback baseline |
| Transaction | Authorized checkout test, shipping and tax validation, order routing and refund procedure |
| Launch | Approved promotion, measurement baseline, manual go/no-go decision |

A missing or stale requirement is not a pass. Do not deploy or publish automatically. Keep private evidence out of this repository.
